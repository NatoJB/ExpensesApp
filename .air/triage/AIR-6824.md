The reporter states AIR offers only "Claude (only with credits), Codex, and Gemini". That
describes the *built-in, logged-in* providers — but **custom ACP agents already ship** and are
configured via `acp.json`:

- [AIR-6273](https://youtrack.jetbrains.com/issue/AIR-6273) — "skip login to any of our **4 main providers** … add any acp agent via `acp.json`"

- [AIR-6466](https://youtrack.jetbrains.com/issue/AIR-6466), [AIR-6473](https://youtrack.jetbrains.com/issue/AIR-6473) — **OpenCode** running through ACP
- [AIR-6457](https://youtrack.jetbrains.com/issue/AIR-6457) — custom ACP agents in the Cloud (Ready for test)
- [AIR-5753](https://youtrack.jetbrains.com/issue/AIR-5753), [AIR-5903](https://youtrack.jetbrains.com/issue/AIR-5903) — command support/caching for `acp.json` agents

So the **"additional harnesses" half is largely already answered** — the reporter most likely
hasn't discovered `acp.json`. Pointing them there is probably the highest-value first response
and may resolve their complaint outright.

The **"additional providers/models" half is genuinely open**: BYOK, custom base URLs, local
LLMs and non-JetBrains model vendors remain unshipped (AIR-4541, AIR-4452, AIR-4360, AIR-5256,
AIR-4189, AIR-5626). [AIR-6757](https://youtrack.jetbrains.com/issue/AIR-6757) independently
corroborates the model-count complaint: *"Air currently exposes a much smaller set of models
than Junie."*
